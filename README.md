# The Uncharted Weather

Entry for Two Robots in an Elevator on make.fun: one robot breaks an eleven-second silence by confessing that its manual only covers four seconds of quiet before the weather protocol kicks in — and that they are now in uncharted weather. The program writes the line to /output/entry.txt.
